# Duos

Duos is a 3D Unity-based game I started making at about June 2026.
It's a sports game that will feature volleyball and soccer, and more to come in the future.

It'll be free when I publish it to steam.

This game is my StarDance Project, which is a programme for 13-18 year olds globally where you can build hardware/software projects that are STEM related and get free prizes shipped to them. (I'm currently trying to get a BambuLab A1 mini)

It is written in C# (Unity coding language).

## Current features
- Basic 3D Physics-based volleyball
- Fully functional offline volleyball (other modes are unavailable) with a tutorial and friendly match mode
- Built with Unity 2022.3

## Future features
- Soccer (to be implemented before release)
- More sports
- Arcade mode for difficult sports
- Local multiplayer (will be implemented before release)

## Try it/download from GitHub
1. Download the zip file from the GitHub releases page on this repo
2. Extract the zip file on your computer (it works only for Mac and Windows)
3. Open the actual game file, and you should be able to play :) Enjoy!

## Controls - For volleyball (which is the only currently available mode)
- WASD Space to move and jump
- Left click to bump when on ground and spike when in air
- F to set
- Shift to lock cursor in screen
- P to pause game and open the pause menu
