# Duos

Duos is a 3D Unity-based game I started making at about June 2026.
It's a sports game that will feature volleyball and soccer, and more to come in the future.

It'll be free when I publish it to steam.

## Current features
- Basic 3D Physics-based volleyball
- Built with Unity 2022.3

## Future features
- Soccer (to be implemented before release)
- More sports
- Arcade mode for difficult sports
- Local multiplayer (will be implemented before release)

## Controls
- WASD Space to move and jump
- Left click to bump when on ground and spike when in air
